# SpendPilot AI

AI-powered SaaS platform that audits company AI tool spending and generates optimization recommendations to reduce infrastructure costs.

## Live Demo

Frontend:
https://spendpilot-ai-ochre.vercel.app

Backend:
https://spendpilot-backend-84ep.onrender.com

---

## Features

- AI tool spending audit
- Cost optimization recommendations
- Savings analysis dashboard
- Interactive analytics charts
- Public shareable reports
- MongoDB report persistence
- Responsive modern UI
- SaaS-style architecture
- Full-stack MERN application

---

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Recharts
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

### Deployment
- Vercel (Frontend)
