# SpendPilot AI — Architecture Overview

## System Overview

SpendPilot AI is a full-stack MERN SaaS application designed to analyze organizational AI tooling spend and generate optimization recommendations.

The platform consists of:

- React frontend (client)
- Express.js backend API (server)
- MongoDB Atlas cloud database
- Deployment infrastructure using Vercel and Render

---

# High-Level Architecture

User → React Frontend → Express API → MongoDB Atlas

The frontend collects AI tooling information from users, sends it to the backend API for persistence, and displays optimized audit recommendations generated by the audit engine.

# API Design

## POST /api/reports

Creates and stores audit reports.

### Request Body

```json
{
  "tools": []
}
```

### Response

```json
{
  "_id": "reportId"
}
```

### GET /api/reports/:id

Fetches a public report by ID.

### Response

```json
{
  "tools": [],
  "results": {}
}
```

# Audit Engine Design

The audit engine uses rule-based optimization heuristics.

## Current Rules

### Small Team Optimization

Downgrades Team plans for small organizations.

### Enterprise Right-Sizing

Recommends Business plans when Enterprise plans are underutilized.

### Workflow Optimization

Suggests specialized coding tools for development-heavy use cases.
